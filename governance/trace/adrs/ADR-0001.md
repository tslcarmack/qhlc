# ADR-0001：模块化单体与 C# 为主

## 状态

已接受。

## 背景

2D RPG 需要可维护的模块边界，并支持 AI 在 Cursor 中安全修改。

## 决策

1. 采用 **模块化单体**：九个业务模块，各对应独立 C# 程序集。
2. **Godot 4 + C# 为主**；GDScript 默认禁止，仅 Core 可经 ADR 开放。
3. 模块依赖以 `governance/registry/modules.yaml` 与 csproj `ProjectReference` 双源校验。
4. CI 不运行 Godot 编辑器；逻辑验证在 `dotnet test` 与治理 CLI 完成。

## 后果

- 新增模块或跨模块引用须更新 manifest 并开 CHG。
- 游戏宿主 `Qhlc.Game` 引用全部模块，便于 Godot 场景挂载。
